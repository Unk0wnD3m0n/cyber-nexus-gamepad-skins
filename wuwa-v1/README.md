## 🎨 Design

Classic **DualShock 4** silhouette, **CYBER NEXUS / WUTHERING WAVES** branding, custom **resonance-wave symbols on both analog sticks**, turquoise/jade shell and illuminated button effects with gold detailing.

## 🎮 Try the controller

Open **TRY CONTROL**, connect a compatible controller through USB/Bluetooth and press any button in Chrome or Edge to activate Gamepad API input tracking.

**D-pad • △ ○ × □ • L1/R1 • L2/R2 • Analog sticks and L3/R3 • Create/Options • PS button • Touchpad**

[Input diagnostic mode](https://unk0wnd3m0n.github.io/cyber-nexus-gamepad-skins/wuwa-v1/?bg=1&debug=1).
