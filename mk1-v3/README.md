# CYBER NEXUS — Mortal Kombat 1 Sub-Zero V3

New modular, realistic-style SVG DualSense visual prototype created independently of mk1-v2. Inspired by Dracula's modular approach; artwork is original.

## Test
- [Dark preview](https://unk0wnd3m0n.github.io/cyber-nexus-gamepad-skins/mk1-v3/?bg=1)
- [Transparent overlay](https://unk0wnd3m0n.github.io/cyber-nexus-gamepad-skins/mk1-v3/)

Connect DualSense through USB or Bluetooth in Chrome/Edge, press a button, then test D-pad, face buttons, analog sticks, bumpers, triggers, Create/Options, touchpad and PS button. V2's Gamepad API input engine is preserved. Validate physical alignment and rendering before production streaming. OBS Browser Source may not expose controllers; use window capture if needed. No files in V2 or original MK1 were overwritten.
