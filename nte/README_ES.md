# 🌆 Control Cyber Nexus × Neverness to Everness

Esta carpeta contiene el skin dedicado de **Neverness to Everness (NTE)** para GamePad Viewer, creado para los streams de Cyber Nexus.

## Recursos

Todo el diseño específico de NTE se encuentra dentro de `nte/assets/` y se mantiene completamente separado de los skins de Wuthering Waves y Mortal Kombat 1.

Archivos:

- `base.png`
- `dpad.png`
- `sticks.png`
- `face-buttons.png`
- `menu-buttons.png`
- `bumpers.png`
- `triggers.png`

La hoja de estilos oficial es `nte-gamepad.css`.

## 🎮 GamePad Viewer

Este control utiliza el diseño **PS4 White / DS4 (`s=8`)** de GamePad Viewer y carga el skin de Cyber Nexus mediante CSS personalizado alojado en GitHub Pages.

Orden actual de desarrollo:

**Base del control → calibración del D-pad → sticks analógicos → botones principales → Create/Options → L1/R1 → L2/R2 → clics de los sticks**

> 🛠️ El diseño del control está instalado y la calibración de las entradas en vivo se encuentra actualmente en desarrollo.
